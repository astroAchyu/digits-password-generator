# 🔢 digits-password-generator

## 🔐 Digits Password Generator (Python)

A simple Python program that generates a **random numeric password** based on the number of digits entered by the user.

This project is beginner-friendly and ideal for learning basic Python concepts like **user input, arithmetic operations, and random number generation**.

---

## 📌 Features

- Generates **numeric passwords only**
- User can choose the **number of digits**
- Ensures the password has **exactly the required length**
- Uses Python’s built-in random module
- Lightweight and easy to understand

---

## 🛠️ Technologies Used

- Python 3  
- random module  

---

## 🧠 How the Code Works

1. User enters the number of digits needed.
2. The program calculates:
   - Minimum possible number for that digit length
   - Maximum possible number for that digit length
3. A random number is generated within that range.
4. The password is displayed to the user.
